# SMS Spam Detection using Machine Learning

## Project Overview
This project uses machine learning to classify SMS messages as Spam or Ham.

## Dataset
- Total messages: 5572
- Ham messages: 4825
- Spam messages: 747
- No missing values

## Tools and Technologies
- Python
- Pandas
- Scikit-learn
- TF-IDF Vectorization

## Model Performance
- Accuracy: 96.05%
- Spam Precision: 1.00
- Spam Recall: 0.70
- Spam F1-score: 0.83

## Purpose
The purpose of this project is to identify spam messages using machine learning.
